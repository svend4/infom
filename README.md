# InfoM — геометрическая GraphRAG-система

Прототип для индексации документов в граф знаний и поиска с генерацией ответов. Проект сочетает локальные, глобальные и гибридные запросы с геометрическими сигнатурами, поиском по графу и визуализацией.

Карту модулей см. в `CLAUDE.md`; материалы проекта находятся в `docs/`.
